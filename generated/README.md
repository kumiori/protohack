# Generated aperture artifacts

This directory is reserved for explicitly generated, reviewable projections. Generated
files must never silently modify the canonical Markdown in `content/experiments/`.

For V0, Git is the provenance system for authored content. The protocol aperture begins
where Git stops: it records which stable page and directive an interaction belongs to,
its participant, status, value, comment and time. A future protocol graph may become
canonical; until then, Markdown remains canonical and generated material is advisory.
