# protocol-lab working agreement

## Origin

This package emerged from Protocol Hack's Protocol Laboratory, where TCP was
initial experimental content. TCP is evidence of the abstraction, not the
abstraction itself.

## Purpose

Turn authored protocol definitions into deterministic, inspectable executions
whose histories can be replayed and interpreted.

## Invariants

Preserve deterministic semantics, explicit participant state, typed
transitions, event history, invariant evaluation, reproducible replay, stable
evidence linkage, and the distinction between events and human interpretation.

Before extending the package ask: is this protocol semantics, or merely one
protocol's content? If it is content, keep it outside the package.
